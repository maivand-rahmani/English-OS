# Resource Need Specifications

## Purpose

This document defines the resource requirements for every block in both roadmap templates.

Each block specification answers:

- What type of resource does this block need?
- What CEFR range must it cover?
- What skills/subskills must it target?
- What role (CORE / SUPPORTING / STRETCH) does each resource fill?
- What pedagogical goal must the resource serve?

These specs drive Phase 2 (Hidden Gem Research) and Phase 3 (Evaluation & Curation).

---

## Resource Requirement Template

Every block should eventually have:

| Role | Count | Description |
|------|-------|-------------|
| CORE | 1 | The primary learning resource for this block. Must directly teach or practice the target skill. |
| SUPPORTING | 1-2 | Complementary resources that reinforce, extend, or provide alternative explanation. |
| STRETCH | 0-1 | Optional harder resource for learners who finish early or want a challenge. |

## Template 1: Beginner Self-Learner Reset — Resource Needs

### Stage 1: Build a Safe Base

#### Block 1.1: Build simple sentences about yourself

**Type**: LEARN
**CEFR**: A1
**Primary Skill**: Grammar (simple sentence order)
**Supporting Skill**: Speaking (self-introduction)

| Role | Resource Need |
|------|---------------|
| CORE | A structured lesson/course unit at A1 that teaches subject-verb-object sentence patterns with personal identity vocabulary. Must include clear examples and simple exercises. Ideally interactive or video-based. |
| SUPPORTING | A quick grammar reference for checking sentence structure during practice. Should be text-based and searchable. |
| STRETCH | A short video or reading at A1 level demonstrating simple self-introductions by real speakers. |

#### Block 1.2: Build starter vocabulary for daily life

**Type**: PRACTICE
**CEFR**: A1
**Primary Skill**: Vocabulary (everyday routines)
**Supporting Skill**: Reading (key details)

| Role | Resource Need |
|------|---------------|
| CORE | A vocabulary resource organized by daily life topics (family, time, routines, food). Must present words in context with images or example sentences. Ideally interactive with audio. |
| SUPPORTING | A dictionary/reference tool learners can use to look up words while building their personal word bank. |
| STRETCH | A simple A1-level reading text that demonstrates the target vocabulary in a coherent story or description. |

#### Block 1.3: Foundation checkpoint

**Type**: CHECKPOINT
**CEFR**: A1
**Primary Skill**: Grammar (simple sentence order)

| Role | Resource Need |
|------|---------------|
| CORE | A self-assessment tool or exercise set that tests basic sentence formation and vocabulary recall at A1 level. Must give clear right/wrong feedback. |
| SUPPORTING | A review sheet or reference card summarizing the key patterns from blocks 1.1 and 1.2. |

### Stage 2: Start Understanding

#### Block 2.1: Understand slow everyday English

**Type**: PRACTICE
**CEFR**: A1 → A2
**Primary Skill**: Listening (listening for gist)
**Supporting Skill**: Vocabulary (everyday routines)

| Role | Resource Need |
|------|---------------|
| CORE | Audio or video content with very slow, clear speech about everyday topics. Must include transcripts. Ideal: learner-level podcasts or video series with graded language. |
| SUPPORTING | A second listening resource at a slightly faster pace for progression. Could be short videos with subtitles. |
| STRETCH | Authentic but accessible audio on familiar topics (slow news, learner podcasts) to build confidence with real content. |

#### Block 2.2: Read simple personal texts

**Type**: PRACTICE
**CEFR**: A1 → A2
**Primary Skill**: Reading (reading for key details)
**Supporting Skill**: Vocabulary (personal information)

| Role | Resource Need |
|------|---------------|
| CORE | A collection of very short texts — personal profiles, simple messages, short descriptions — at A1-A2 level. Must have comprehension questions or tasks. |
| SUPPORTING | A reference dictionary for quick word lookups during reading. |
| STRETCH | A slightly longer text (short article or story) at A2 level to stretch reading stamina. |

**Type**: LEARN
**CEFR**: A2
**Primary Skill**: Grammar (past tenses)
**Supporting Skill**: Grammar (present tenses)

| Role | Resource Need |
|------|---------------|
| CORE | A structured grammar resource that clearly explains past simple, present perfect, and past continuous with contrastive practice. Must address the most common A2→B1 tense confusion points. |
| SUPPORTING | A quick-reference grammar guide for checking tense formation during practice. |
| STRETCH | A set of mixed-tense exercises at B1 level for learners who master the basic distinction quickly. |

#### Block 1.2: Expand active vocabulary

**Type**: PRACTICE
**CEFR**: A2
**Primary Skill**: Vocabulary (places and travel)
**Supporting Skill**: Vocabulary (work and study)

| Role | Resource Need |
|------|---------------|
| CORE | A thematic vocabulary resource covering travel, work, and study contexts at A2-B1 level. Must include collocations and example sentences. |
| SUPPORTING | A dictionary/thesaurus tool for independent word exploration. |
| STRETCH | A reading or listening text that uses the target vocabulary in a natural context. |

#### Block 1.3: Foundation repair checkpoint

**Type**: CHECKPOINT
**CEFR**: A2
**Primary Skill**: Grammar (past tenses)

| Role | Resource Need |

## Design Constraints

1. **Prefer FREE resources first** — EnglishOS curates free content. Paid content must be exceptional to justify inclusion.
2. **Prefer evergreen resources** — Avoid resources tied to a specific exam, course start date, or short-term event.
3. **Prefer resources with transcripts/closed captions** — Self-learners need text support for audio content.
4. **Prefer resources designed for self-study** — Classroom materials that require a teacher are less useful.
5. **Avoid resources behind login walls** — If a resource requires account creation, it must be worth the friction.
