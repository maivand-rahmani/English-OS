# Roadmap Futures

## Purpose

This section holds future roadmap documents for English OS after the launchable V1 MVP is complete.

These docs exist to define what comes next without interrupting the active V1 execution path.

## Scope

Use this section for:

- post-V1 roadmap planning
- V2 structure definition
- future expansion sequencing
- major navigation or workflow growth beyond the launch MVP

Do not use this section as the active work tracker while V1 is still incomplete.

## Futures Principle

Future roadmap documents should:

- assume the current roadmap has already been completed
- avoid moving unfinished V1 work into later phases
- describe the next coherent product expansion
- stay aligned with the product thesis and information architecture

## Tracking Rule

[V1 MVP Roadmap](../v1-mvp-roadmap.md) remains the active implementation tracker until V1 is fully complete.

Future roadmap docs are planning documents until the project explicitly graduates past V1.
