# Roadmap Expanded

## Purpose

This document defines the complete specification for both V1 roadmap templates:

1. **Beginner Self-Learner Reset** (PRE_A1 → A2)
2. **Intermediate Self-Learner** (A2 → B1/B2)

For each template, it defines every stage, every block, block type, CEFR range, estimated time, skill mappings, and subskill mappings.

---

### Learner Profile

- Knows isolated words but cannot form complete sentences
- Has studied before but feels like starting over
- Needs maximum clarity, small wins, and repeatable patterns
- Has 20-30 minutes per day for English

### Stage 1: Build a Safe Base

**Type**: FOUNDATION
**CEFR**: PRE_A1 → A1
**Weeks**: 4
**Purpose**: Create the first stable layer of sentence patterns and everyday language. Reduce overwhelm by focusing on the smallest set of patterns that unlock useful beginner English.

#### Block 1.1: Build simple sentences about yourself

| Supporting Skill | speaking → self-introduction-and-daily-talk |

**Purpose**: This block turns basic grammar into usable identity language instead of isolated rules.

**Why Now**: A beginner needs early wins that sound personal and real, not textbook-only output.

## Template 2: Intermediate Self-Learner

### Learner Profile

- Has studied English for months or years but progress feels uneven
- Can handle routine situations but struggles with connected output
- Knows more than they can produce
- Has gaps in foundational grammar
- Needs structure more than new information

### Stage 1: Foundation Repair

**Type**: FOUNDATION
**CEFR**: A2
**Weeks**: 3
**Purpose**: Identify and fix the most common intermediate weak points: past tense, present perfect, conditionals, and vocabulary gaps.

#### Block 1.1: Fix tense gaps

| Field | Value |
|-------|-------|
| Slug | `fix-tense-gaps` |
| Block Type | `LEARN` |
| CEFR | A2 |
| Estimated Minutes | 45 |
| Recommended Sessions | 3 |
| Primary Skill | grammar → past-tenses |
| Supporting Skill | grammar → present-tenses |

**Purpose**: Close the most common intermediate grammar gap — inconsistent tense usage, especially past simple vs. present perfect.

**Why Now**: Most intermediate learners have shaky tense control. Fixing this first makes everything else easier.

#### Block 1.2: Expand active vocabulary

| Field | Value |

| Supporting Skill | vocabulary → work-and-study-vocabulary |

**Purpose**: Move beyond everyday routine vocabulary into the next layer: travel, work, and study contexts.

**Why Now**: Vocabulary stagnation is a primary cause of the "intermediate plateau."

#### Block 1.3: Foundation repair checkpoint

| Field | Value |
|-------|-------|
| Slug | `foundation-repair-checkpoint` |
| Block Type | `CHECKPOINT` |
| CEFR | A2 |
| Estimated Minutes | 20 |
| Recommended Sessions | 1 |
| Primary Skill | grammar → past-tenses |

**Purpose**: Verify that tense control and vocabulary range are solid before moving to input-heavy stages.
